# eGLV Business Development Demo

Management-focused prototype for a Stage-Gate Business Development application for the eGLV context.

## Deployable App

The Vercel deployable app is located in:

```text
eglv-demo-app
```

When importing this repository into Vercel, set:

```text
Root Directory: eglv-demo-app
Framework Preset: Other
Build Command: npm test
Output Directory: public
```

## Demo Flow

1. Login with `management@eglv-demo.de`
2. Confirm visual MFA
3. Open the management dashboard
4. Show the Stage-Gate Kanban
5. Open Pflanzenkohle/Pyrolyse at Gate 2
6. Decide `Go`
7. Continue to Stage 3
8. Simulate Gate 3 failure
9. Review archive and reminder
10. Show Microsoft infrastructure fit in settings
